# 📊 Aakrti — Data Analyst Internship Portfolio

Data Analytics Internship at ApexPlanet Software Pvt. Ltd. — 4 tasks covering the complete data analytics workflow: cleaning, exploration, deep-dive analysis, and statistical validation.

## 📁 Projects

### Task 1 — Data Cleaning
Cleaned 1,005 raw sales records using Python & Pandas; 995 retained after fixing missing values, duplicates, and bad dates.
🔗 [Repo](https://github.com/Aakrti1211/Sales-Data-Cleaning-Project)

### Task 2 — EDA & Business Intelligence Dashboard
SQL cleaning + interactive Excel dashboard answering 7 core business questions across 1,500 orders.
🔗 [Repo](https://github.com/Aakrti1211/Eda-Business-Intelligence-Dashboard)

### Task 3 — Deep-Dive Analysis & Interactive Dashboard
Python + Tableau dashboard defining KPIs across 5,111 orders; identified a major profitability gap in Furniture.
🔗 [Repo](https://github.com/Aakrti1211/Deep-Dive-Analysis-Interactive-Dashboard)

### Task 4 — Data Storytelling & Statistical Validation
Hypothesis testing (Welch's t-test, p < 0.001) validating the profitability gap, with business recommendations.
🔗 [Repo](https://github.com/Aakrti1211/Data-Storytelling-Statistical-Validation-Project)
